# Hyperliquid trader-kandidaten (consistent op 30D + All-time)

Methode: elk wallet hieronder stond zowel in de top-200 van de 30-dagen-ranglijst
(gesorteerd op PNL) ALS in de top-200 van de All-time-ranglijst (ook op PNL) van
https://app.hyperliquid.xyz/leaderboard. Dat is het "niet toevallig deze week
geluk gehad"-filter waar we het over hadden. Filter van Hyperliquid zelf blijft
gelden: min. 100k USDC accountwaarde, min. 10M USDC volume.

Eerste ronde (# 1-13) was top-100 op beide ranglijsten. Tweede ronde (# 14-28)
is dezelfde methode maar dieper doorzocht: top-200 op beide ranglijsten, om
dichter bij de 20-30 wallets te komen die oorspronkelijk het idee was.

verkeerd/afgekapt karakter zoals bij de eerdere WebFetch-poging).
